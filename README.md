# This is a simple game demo 

## ✨Features
- A movable character basied on FSM
  ```
  Can move _direction ✅️
  Can scroll         ✅️
  Can dash           ⏳(doing)
  Can jump           ⏳(doing)
  ```
- A camera that follow player basied on FSM
- Animator state machine & conditions
